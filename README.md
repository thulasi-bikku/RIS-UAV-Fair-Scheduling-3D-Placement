This repository contains the simulation code and analytical results for the FAIR-RIS-UAV framework proposed in the paper:

“RIS Enhanced Dual-Hop UAV Relaying with Fair User Scheduling and joint 3D Position Optimization over Mixed α–κ–μ and Rayleigh Fading Channels”

Key features:
- Elevation-dependent α–κ–μ first hop + RIS-assisted Rayleigh second hop
- CDF-based fair scheduling (exact 1/N access probability + multiuser diversity)
- Closed-form outage probability, diversity order, ergodic throughput, Jain’s fairness index and ASER
- Multi-start 3D UAV placement optimization
- Monte Carlo validation for fair, max-SNR and round-robin schedulers
